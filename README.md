# Complete Gaming Optimizer

One script to apply several Windows gaming tweaks at once.

## Features

- Disables Fullscreen Optimizations.
- Disables GameDVR.
- Applies performance-focused power settings.
- Adds network latency tweaks.
- Disables unnecessary background services.
- Applies input-latency improvements.

## How to use

1. Open PowerShell as Administrator.
2. Run the script:

```powershell
.\complete-gaming-optimizer.ps1
```

3. Restart your computer.

## Notes

- Best for gamers who want a fast all-in-one setup.
- Some changes may need a reboot to take effect.
- Always test your system after changing performance settings.
